# README — Планирование: Задачи и Таймер Помодоро

Приложение состоит из двух страниц и работает полностью в браузере:

- `tasks.html` — страница **«Задача»** (добавление/редактирование/выполнение и выбор фокуса)
- `pomodoro.html` — страница **«Таймер Помодоро»** (режимы, старт/пауза/сброс, статистика и настройки)

Все данные (задачи, выбранный фокус, счётчики и настройки таймера) сохраняются в `localStorage`, поэтому после обновления страницы всё продолжает работать.

## Возможности

1. Задачи
1. Добавление новых задач.
1. Редактирование названия задачи.
1. Отметка задачи выполненной/невыполненной.
1. Удаление задачи.
1. Выбор задачи как **фокуса** (подсвечивается и отображается в заголовке).
1. Фильтры списка: `Все`, `Активные`, `Выполненные`.
1. Статистика по задачам: всего / активные / выполненные.
1. Помидоры
1. Работа/короткий перерыв/длинный перерыв.
1. Учёт завершённых **помидоров**:
   - общий счётчик
   - помидоры, привязанные к выбранной задаче (когда выбран фокус, рабочие сессии увеличивают счётчик именно этой задачи).
1. Автоматический переход между режимами после завершения таймера.
1. Сигнал завершения (визуальный + звук через Web Audio API, если браузер разрешает; плюс вибрация на поддерживаемых устройствах).

## Как пользоваться (пошагово)

### 1) Добавьте задачи
1. Откройте `tasks.html`.
2. Введите название в поле и нажмите **«Добавить задачу»**.
3. (По умолчанию) первая созданная задача автоматически станет выбранной.

### 2) Выберите задачу для фокуса
1. На странице задач нажмите **«Выбрать»** у нужной задачи.
2. Если нужно снять фокус — нажмите **«Снять фокус»** (или кликните по самой задаче в списке — выбор переключается).
3. Название выбранной задачи отображается вверху на обеих страницах.

### 3) Запустите таймер Помодоро
1. Откройте `pomodoro.html`.
2. При необходимости переключите режимы (кнопки над таймером): **Работа**, **Короткий перерыв**, **Длинный перерыв**.
3. Нажмите **«Старт»**.
4. Для остановки нажмите **«Пауза»**.
5. Для возврата к началу режима нажмите **«Сброс»**.

### 4) Как учитываются «помидоры»
1. Помидор считается при завершении **рабочего режима** (`Работа`).
2. Если на момент завершения выбран фокус, то помидор увеличит счётчик именно для этой задачи.
3. Если фокус не выбран — помидор всё равно увеличит общий счётчик, но не привяжется к задаче.
4. Длинный перерыв включается автоматически каждые `N` рабочих помидоров (по умолчанию `4`, настраивается).

## Настройки таймера
Откройте `pomodoro.html` и в блоке **«Настройки таймера»** задайте:

- `Работа (мин)` — длительность работы
- `Короткий перерыв (мин)` — длительность короткого перерыва
- `Длинный перерыв (мин)` — длительность длинного перерыва
- `Длинный перерыв каждые N помидоров` — как часто после рабочих сессий будет длинный перерыв

Нажмите **«Сохранить настройки»**. Значения сохранятся в браузере.

## Тема оформления
Тема переключается кнопкой в правом нижнем углу:
- тёмная/светлая

Выбор сохраняется в `localStorage`.

## Важно
- Если открыть одновременно обе страницы, они будут делить один набор данных в `localStorage`.
- Приложение рассчитано на работу локально без серверной части.
